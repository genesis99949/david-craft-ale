# Beer gallery photographs

Eight AI-generated portfolio product photographs: rear packaging concept and tabletop scene for Blonde Ale, Amber Pale Ale, IPA and Dark Lager. Generated with the built-in image generation tool using the existing bottle assets as identity references. Rear labels are new concept designs, not photographs of production packaging.

Master PNG files and responsive WebP derivatives are stored here. The exact generation prompts are recorded in `prompts.json`.
